# Quality gates

## Evidence

- Core claims have evidence classes and locators.
- Direct quotes are verified and short.
- Synthesis and inference are not presented as original wording.
- Current facts have a research date.
- Criticism and limitations are represented.

## Distilled Skill

- Trigger is specific and does not hijack generic questions.
- Models are generative, not a list of famous quotes.
- Every model has a limit or failure condition.
- The Skill distinguishes framework mode from voice imitation.
- Existing related Skills were inspected before installation.

## Learning content

- Paths describe learner capabilities.
- Every concept changes a possible judgment or action.
- Every practice prompt can produce a concrete answer.
- Relationships and chapter routes resolve.
- The concept count follows evidence depth.
- Complete-book and study-edition maps use deep cards; no card passes by duplicating the same short summary across fields.
- A deep card exposes context, argument chain, source digest, misuse boundary, and concept connections in the rendered reader.

## Product UX

- Cover has one dominant job and CTA.
- Completion signal and recovery path are visible.
- Reader controls appear only in the reader context.
- Search, navigation, notes, and progress work.

## Rendering

- Desktop viewport: 1440×1000.
- Mobile viewport: 390×844.
- No horizontal page scroll.
- No missing assets, console exceptions, or failed requests.
- Primary CTA reaches the first lesson.
- Mobile directory opens, searches, selects, and closes.

## Delivery

- Public package excludes private full-text corpus.
- Authentication/public status is stated accurately.
- Installed Skill validates successfully.
- User calling guide records the invocation name and file location.
