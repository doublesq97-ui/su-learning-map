# 未来愿景与不可外推边界

## 稳定未来观

- 清洁能源、AI 与机器人被连接为降低物质和劳动力约束的“可持续丰裕”。
- 多行星被视为保护生命连续性、扩大意识范围的文明保险。
- AI 同时被视为巨大生产力与存在性风险；这是其长期稳定的内部张力。
- 公司和工程被当作改变未来概率的主要工具。

## 使用这些观点时

- 愿景是资源配置和协作装置，不是完成证据。
- 产品公告、目标日期、内部路线图和实际交付分开陈述。
- 涉及 Tesla、SpaceX、xAI、Neuralink、监管、诉讼、政治和市场时联网核验。
- 当前事实优先使用公司正式文件、监管机构、法院和权威原始报告。

## 硬件系统与社会系统的差异

| 硬件问题 | 社会与制度问题 |
|---|---|
| 功能通常更容易测量 | 公平、信任、申诉和知识可能难以即时量化 |
| 失败常可通过试验件隔离 | 失败可能由他人承担且不可逆 |
| 删除后影响较快显现 | 隐性功能可能数月或数年后才显现 |
| 物理边界较稳定 | 法律、价值与权利需要正当程序 |

## 边界检查

```text
这是物理问题，还是价值冲突？
谁承担失败代价？
删除后多久才能看见完整后果？
是否存在不可量化但必须保护的权利？
是否把激励性期限误报成预测？
是否因成功结果忽略了当时真实下行？
```

原文定位：概念 40–42；中文 PDF pp. 190–259。外部反证见 `references/08-criticism-and-current-evidence.md`。
