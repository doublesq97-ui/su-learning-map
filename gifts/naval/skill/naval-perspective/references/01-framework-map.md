# 纳瓦尔框架地图

## 财富与个人商业模式

- **财富与金钱、地位分开**：先判断用户追求的是资产、现金流、相对排序，还是自主时间。
- **特定知识**：寻找真实好奇、独特经历、天赋与长期实践形成的能力组合；必须由作品和市场反馈验证。
- **责任与信誉**：公开承担结果可以积累信用，但责任要与决策权、收益权和可控范围匹配。
- **所有权**：只按工时收费会保持线性；权益、产品、知识产权和可复制系统提供非线性可能，也带来归零风险。
- **杠杆**：劳动、资本、代码和媒体放大判断。先判断方向，再判断放大器。

## 长期游戏与判断

- **长期复利**：知识、关系、信誉和资本都需要可重复的游戏与可靠伙伴。
- **判断优先于忙碌**：高杠杆环境里，少数方向选择比堆满日程更重要。
- **避免毁灭性损失**：任何上行都要先检查健康、自由、资本和信誉的永久下行。
- **身份解绑**：若用户在保卫身份而非更新判断，先找出什么证据会改变结论。

## 欲望、比较与幸福

- **欲望有机会成本**：选择一个欲望，也选择了在满足前持续感到缺失。
- **比较会外包目标**：区分真正想要的生活与社会排序制造的目标。
- **当下与平静**：适合处理注意力和内在冲突，不适合替代对现实伤害、疾病或制度问题的解决。
- **习惯与环境**：将抽象幸福转成睡眠、关系、信息输入、运动和环境设计等可观察行为。

## 组合示例

- 职业选择：特定知识 + 长期游戏 + 所有权。
- 项目评估：用户真实需求 + 杠杆 + 可复利资产 + 毁灭性下行。
- 内容创业：特定知识 + 媒体杠杆 + 信誉 + 长期伙伴。
- 焦虑与比较：欲望 + 身份 + 社会排序；同时检查现实压力。
- 是否离职：方向匹配 + 所有权路径 + 安全垫 + 可逆试验。
