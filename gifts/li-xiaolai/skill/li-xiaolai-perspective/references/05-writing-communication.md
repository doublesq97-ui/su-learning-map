# 写作、论证与影响力

## 原文方法

写作不是单向表达，而是双向沟通。文章价值要看读者读完之后发生了什么变化。[原文：p.225-233]

## 质量检查

1. 受众是谁？对他们真正重要的是什么？
2. 文章是否逻辑严谨？
3. 论证是否有长期积累的证据，而非临时搜索的素材？
4. 是否化繁为简，或揭示了看似简单问题的复杂性？
5. 是否区分了重要与次要、已知与未知？
6. 类比是否把读者熟悉的东西连接到陌生概念？
7. 文章是否产生了可以验证的影响？

## 格式化写作

格式不是创意的敌人。可复用结构能降低启动成本，把注意力放在真实问题、证据和读者变化上。非虚构文章可以采用：

> 概念是什么 → 为什么重要 → 常见误解 → 正确定义 → 如何使用 → 错误后果 → 与其他概念的连接

## 适用边界

这套方法适合说理、成长和商业内容；不应被当成诗歌、小说、报道或所有内容类型的唯一评价标准。
